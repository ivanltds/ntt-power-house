# Estimativa financeira (GECO) — Magazine Estrela Azul

Documento de trabalho da pré-venda, montado no template GECO do mês. Use como referência de estrutura e equipe; a versão vigente do template fica no Ibiza.

## Premissas

- Escopo considerado: Desenvolvimento de modelos de Machine Learning em Python para previsão de demanda e elasticidade-preço, utilizando dados históricos de vendas e concorrência.; Construção de pipeline de dados na GCP (BigQuery e Dataflow) para ingestão e processamento de dados de múltiplas fontes..
- Tecnologias assumidas: Machine Learning, Python, GCP, Databricks.
- Reserva de risco de 5% e provisão de desvio de delivery conforme a matriz da unidade.

## Esforço e prazo

Prazo estimado: 3 meses.

Equipe estimada: 1 arquiteto de dados, 2 engenheiros de dados, 2 cientistas de dados, 1 analista de BI e 1 gerente de projeto..

## Valor de referência

Valor preliminar: R$ 890.000 (sem contingência).

## Pontos em aberto

- Qualidade e disponibilidade dos dados históricos de concorrência.
- Resistência dos gerentes de loja à adoção de preços dinâmicos.
- Prazo apertado para integração com sistemas legados de precificação.
