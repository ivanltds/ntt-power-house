# Estimativa financeira (GECO) — Laboratório Diagnóstico Preciso

Documento de trabalho da pré-venda, montado no template GECO do mês. Use como referência de estrutura e equipe; a versão vigente do template fica no Ibiza.

## Premissas

- Escopo considerado: Governança de dados com definição de políticas de qualidade e catálogo de dados para 12 fontes distintas.; Pipeline de ingestão e transformação de dados usando Azure Data Factory e Python para processar 500 GB de dados históricos..
- Tecnologias assumidas: Machine Learning, Azure, Python, Power BI.
- Reserva de risco de 5% e provisão de desvio de delivery conforme a matriz da unidade.

## Esforço e prazo

Prazo estimado: 5 meses.

Equipe estimada: 1 arquiteto de dados, 2 engenheiros de dados, 1 cientista de dados, 1 analista de BI e 1 gerente de projeto..

## Valor de referência

Valor preliminar: R$ 250.000 (sem contingência).

## Pontos em aberto

- Qualidade dos dados de fontes legadas comprometendo os modelos.
- Resistência dos usuários na adoção dos dashboards e novas práticas.
- Prazo curto para integração de sistemas heterogêneos.
