# Estimativa financeira (GECO) — Energia Paulista Distribuição

Documento de trabalho da pré-venda, montado no template GECO do mês. Use como referência de estrutura e equipe; a versão vigente do template fica no Ibiza.

## Premissas

- Escopo considerado: Ingestão e tratamento de dados de consumo, cadastro e inspeções usando Databricks e Azure Data Lake; Desenvolvimento de modelo de machine learning para priorização de inspeções com base em padrões de consumo.
- Tecnologias assumidas: Databricks, Machine Learning, Azure.
- Reserva de risco de 5% e provisão de desvio de delivery conforme a matriz da unidade.

## Esforço e prazo

Prazo estimado: 8 meses.

Equipe estimada: 1 arquiteto de dados, 2 engenheiros de dados, 1 cientista de dados sênior e 1 gerente de projeto.

## Valor de referência

Valor preliminar: R$ 1.490.000 (sem contingência).

## Pontos em aberto

- Baixa qualidade dos dados históricos de inspeções
- Resistência das equipes de campo à priorização baseada em modelo
- Dependência de aprovação regulatória para uso de dados de consumo
