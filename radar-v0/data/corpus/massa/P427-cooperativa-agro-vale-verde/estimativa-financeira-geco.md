- Escopo considerado: Implementação de pipeline de dados no Snowflake para integração de fontes internas e externas; Desenvolvimento de modelo de machine learning em Python para scoring de crédito.

- Reserva de risco de 5% e provisão de desvio de delivery conforme a matriz da unidade.
