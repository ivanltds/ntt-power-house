# SOW — Manutenção Preditiva de Ativos com Machine Learning para Operadora Telecom

**Contratante:** Ondas Móvel · **Contratada:** NTT DATA Brasil · **Vigência:** 10 meses a partir do kickoff

## 1. Objeto

Implantar uma solução de manutenção preditiva baseada em machine learning para prever falhas em ativos críticos, reduzindo o tempo de inatividade e os custos de manutenção corretiva.

## 2. Escopo contratado

- Coleta e ingestão de dados de sensores de ativos em tempo real usando Apache Kafka
- Desenvolvimento de pipelines de engenharia de dados em Python para limpeza e transformação
- Implementação de modelos de machine learning no Databricks para previsão de falhas
- Integração dos modelos preditivos com sistemas de manutenção existentes
- Capacitação das equipes de operações em change management para adoção da solução

## 3. Entregáveis e aceite

- Plataforma de dados unificada com ingestão em tempo real via Kafka
- Modelos preditivos treinados e validados com acurácia superior a 85%
- Dashboard de monitoramento de saúde dos ativos para equipes de operações
- Relatório de resultados com indicadores de redução de falhas e custos
- Programa de treinamento e gestão da mudança para 50 colaboradores

Cada entregável é aceito pelo cliente em até 10 dias úteis após a entrega.

## 4. Fora do escopo

Sustentação após a operação assistida, licenças de software e infraestrutura do cliente.

## 5. Valor e condições

Valor total: R$ 680.000, faturado mensalmente conforme o cronograma.
