# SOW — Indicadores ESG e Monitoramento de Emissões com Power BI e Snowflake

**Contratante:** Indústria de Embalagens Plastipack · **Contratada:** NTT DATA Brasil · **Vigência:** 3 meses a partir do kickoff

## 1. Objeto

Implementar uma plataforma de dados centralizada para consolidar e analisar indicadores ESG e emissões, garantindo transparência e suporte à tomada de decisão estratégica.

## 2. Escopo contratado

- Integração de fontes de dados de consumo de energia, água e matérias-primas com Snowflake
- Modelagem dimensional e criação de cubos de dados para análise de emissões no Power BI
- Desenvolvimento de dashboards interativos para monitoramento de KPIs ESG no Power BI
- Implementação de pipeline de dados no Azure Data Factory para carga automatizada
- Definição de políticas de governança de dados e catálogo de métricas ESG

## 3. Entregáveis e aceite

- Documento de arquitetura de dados e governança
- Dashboard executivo de indicadores ESG no Power BI
- Relatório automatizado de emissões de escopo 1 e 2
- Manual de uso e treinamento para equipe interna
- Plano de change management e comunicação

Cada entregável é aceito pelo cliente em até 10 dias úteis após a entrega.

## 4. Fora do escopo

Sustentação após a operação assistida, licenças de software e infraestrutura do cliente.

## 5. Valor e condições

Valor total: R$ 1.220.000, faturado mensalmente conforme o cronograma.
