# Estimativa financeira (GECO) — Rede Hospitalar Santa Clara

Documento de trabalho da pré-venda, montado no template GECO do mês. Use como referência de estrutura e equipe; a versão vigente do template fica no Ibiza.

## Premissas

- Escopo considerado: Integração de dados de CRM (Salesforce) e sistemas transacionais com Databricks na AWS para criação de uma base analítica unificada.; Análise exploratória e engenharia de features para identificar os principais indicadores de churn..
- Tecnologias assumidas: Salesforce, Databricks, AWS.
- Reserva de risco de 5% e provisão de desvio de delivery conforme a matriz da unidade.

## Esforço e prazo

Prazo estimado: 2 meses.

Equipe estimada: 1 arquiteto de dados, 2 engenheiros de dados, 1 cientista de dados e 1 gerente de projeto.

## Valor de referência

Valor preliminar: R$ 1.750.000 (sem contingência).

## Pontos em aberto

- Qualidade dos dados históricos insuficiente para treinamento robusto.
- Resistência das equipes de CRM em adotar os scores preditivos.
- Prazo apertado para integração com sistemas legados.
