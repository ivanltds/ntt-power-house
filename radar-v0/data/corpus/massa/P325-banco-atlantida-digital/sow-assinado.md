# SOW — Assistente Virtual com IA Generativa para Atendimento Bancário Digital

**Contratante:** Banco Atlântida Digital · **Contratada:** NTT DATA Brasil · **Vigência:** 6 meses a partir do kickoff

## 1. Objeto

Implementar um assistente virtual com IA generativa no Azure para automatizar 70% dos atendimentos de baixa complexidade, reduzindo o tempo de resposta para menos de 1 minuto e melhorando a experiência do cliente.

## 2. Escopo contratado

- Desenvolvimento de assistente virtual baseado em modelos de linguagem generativa no Azure OpenAI
- Integração com sistemas legados de atendimento via APIs e automação de processos com Azure Logic Apps
- Implementação de pipeline de dados e orquestração para alimentar o modelo com base de conhecimento interna
- Configuração de mecanismos de segurança, compliance e monitoramento no Azure
- Treinamento e ajuste fino do modelo com dados históricos de atendimento

## 3. Entregáveis e aceite

- Protótipo funcional do assistente virtual integrado ao canal de chat
- Documentação técnica da arquitetura e fluxos de automação
- Modelo de IA generativa treinado e validado com métricas de acurácia
- Relatório de testes de segurança e conformidade
- Manual de operação e plano de treinamento para equipes internas

Cada entregável é aceito pelo cliente em até 10 dias úteis após a entrega.

## 4. Fora do escopo

Sustentação após a operação assistida, licenças de software e infraestrutura do cliente.

## 5. Valor e condições

Valor total: R$ 470.000, faturado mensalmente conforme o cronograma.
