# Template — Entrada de Decisão

Copie o bloco abaixo para o final de `docs/sdlc/DECISIONS.md`, preencha e nunca edite depois de publicado.

```markdown
## DEC-XXXX — <título curto da decisão>

| Campo | Valor |
|---|---|
| ID | DEC-XXXX |
| Data | AAAA-MM-DD |
| Fase / Etapa | <ex.: 2. Desenvolvimento / DEV-01> |
| Tipo | <Aprovação de Gate \| Reprovação de Gate \| Decisão de Escopo \| Decisão Técnica \| Risco Aceito \| Outro> |
| Descrição | <o que foi decidido, em 1-3 frases> |
| Justificativa | <por que> |
| Responsável (autor da proposta) | <agente de IA ou pessoa> |
| Aprovador humano | <nome e papel> |
| Referências | <link do PR / issue / GATE.md / STATUS.md> |
| Supersede | <DEC-XXXX ou "N/A"> |
```
