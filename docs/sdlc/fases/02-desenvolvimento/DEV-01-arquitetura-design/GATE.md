# Gate de Qualidade — DEV-01 Arquitetura & Design Técnico

## Critérios de saída (checklist técnico — preenchido pelo agente de IA)

- [ ] Arquitetura da solução descrita (componentes, camadas, integrações)
- [ ] Modelo de dados e contratos de API/eventos definidos
- [ ] Requisitos não funcionais endereçados (segurança, performance, escalabilidade, observabilidade)
- [ ] Alternativas consideradas e justificativa da escolha documentadas (ADR)
- [ ] Compatibilidade com padrões arquiteturais existentes verificada (ou divergência justificada)

## Aprovação humana obrigatória

Nenhuma etapa avança sem aprovação humana explícita registrada abaixo. IA nunca aprova a própria saída.
