# Gate de Qualidade — NB-04 UI/UX Design

## Critérios de saída (checklist técnico — preenchido pelo agente de IA)

- [ ] Jornada do usuário mapeada para os principais fluxos
- [ ] Wireframes/mockups propostos para cada tela/fluxo relevante
- [ ] Aderência ao design system/guia de estilo verificada (ou exceção justificada)
- [ ] Requisitos básicos de acessibilidade e usabilidade considerados
- [ ] Rastreabilidade entre telas/fluxos propostos e requisitos (NB-02) completa

## Aprovação humana obrigatória

Nenhuma etapa avança sem aprovação humana explícita registrada abaixo. IA nunca aprova a própria saída.
