# Gate de Qualidade — NB-01 Ideação & Discovery

## Critérios de saída (checklist técnico — preenchido pelo agente de IA)

- [ ] Problema de negócio descrito de forma clara e específica (não genérico)
- [ ] Contexto e stakeholders identificados
- [ ] Objetivos de negócio e critérios de sucesso (métricas) definidos
- [ ] Hipóteses e riscos iniciais listados
- [ ] Nenhuma informação crítica de negócio (orçamento, prioridade, stakeholder decisor) ficou sem resposta

## Aprovação humana obrigatória

Nenhuma etapa avança sem aprovação humana explícita registrada abaixo. IA nunca aprova a própria saída.

## Registro de Aprovação Humana

| Campo | Valor |
|---|---|
| Aprovador (nome completo) | |
| Papel / cargo | Product Owner / Sponsor |
| Data da decisão | |
| Decisão | Aprovado / Aprovado com ressalvas / Reprovado |
| Ressalvas (se houver) | |
| Evidências (link do PR) | |

## Efeito

- **Aprovado** → Agente GitHub registra aprovação no commit/PR; Maestro libera **NB-02**.
- **Reprovado** → retorna ao Agente de Ideação com apontamentos; decisão registrada em `DECISIONS.md`.
