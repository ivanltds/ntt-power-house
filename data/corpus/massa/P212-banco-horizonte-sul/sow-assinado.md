# SOW — Governança de Dados e Conformidade LGPD para Banco Horizonte Sul

**Contratante:** Banco Horizonte Sul · **Contratada:** NTT DATA Brasil · **Vigência:** 5 meses a partir do kickoff

## 1. Objeto

Implementar um framework de governança de dados e adequação à LGPD, garantindo a proteção de dados pessoais e a conformidade regulatória em 5 meses.

## 2. Escopo contratado

- Mapeamento e classificação de dados pessoais em 15 sistemas críticos usando Python para automatizar a descoberta.
- Implementação de catálogo de dados e políticas de acesso no Azure Purview.
- Desenvolvimento de pipelines de anonimização e mascaramento de dados com Python e Azure Data Factory.
- Treinamento e change management para 300 colaboradores sobre LGPD e boas práticas de governança.
- Definição de processos de resposta a incidentes e relatórios de conformidade.

## 3. Entregáveis e aceite

- Relatório de mapeamento de dados pessoais e classificação de risco.
- Catálogo de dados implementado no Azure Purview com 500 ativos catalogados.
- Políticas de segurança e acesso a dados documentadas e aprovadas.
- Programa de treinamento em LGPD com 300 participantes e certificação interna.
- Plano de resposta a incidentes e dashboard de conformidade.

Cada entregável é aceito pelo cliente em até 10 dias úteis após a entrega.

## 4. Fora do escopo

Sustentação após a operação assistida, licenças de software e infraestrutura do cliente.

## 5. Valor e condições

Valor total: R$ 1.040.000, faturado mensalmente conforme o cronograma.
