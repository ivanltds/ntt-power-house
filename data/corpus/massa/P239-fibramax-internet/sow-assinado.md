# SOW — Predição de Churn e Retenção para Provedor de Internet via Machine Learning na AWS

**Contratante:** FibraMax Internet · **Contratada:** NTT DATA Brasil · **Vigência:** 4 meses a partir do kickoff

## 1. Objeto

Desenvolver e implantar um modelo de machine learning para prever probabilidade de churn em até 30 dias, permitindo que a equipe de CRM atue com campanhas de retenção direcionadas e reduza a taxa de evasão em 15% até o final do projeto.

## 2. Escopo contratado

- Construção de pipeline de dados na AWS para ingestão e tratamento de dados históricos de clientes, uso e faturamento
- Desenvolvimento de modelo de classificação em Python com algoritmos de Machine Learning para predição de churn
- Integração do modelo com a plataforma de CRM para acionamento automático de ofertas de retenção
- Criação de dashboards de monitoramento de churn e efetividade das ações de retenção em Analytics & BI
- Realização de testes A/B para validar a performance do modelo e ajuste contínuo

## 3. Entregáveis e aceite

- Relatório de análise exploratória e engenharia de features com as principais variáveis preditivas
- Modelo de machine learning treinado e validado com AUC superior a 0,85
- API de scoring integrada ao CRM para consulta em tempo real da probabilidade de churn
- Dashboard de acompanhamento de churn e resultados das campanhas de retenção
- Documentação técnica e plano de sustentação do modelo

Cada entregável é aceito pelo cliente em até 10 dias úteis após a entrega.

## 4. Fora do escopo

Sustentação após a operação assistida, licenças de software e infraestrutura do cliente.

## 5. Valor e condições

Valor total: R$ 2.110.000, faturado mensalmente conforme o cronograma.
