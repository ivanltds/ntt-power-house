# Apresentação Comercial — Corretora Valor Alto

## Slide 1 — Plataforma Lakehouse para Análise de Dados Financeiros com Azure e Databricks

Corretora Valor Alto · Serviços Financeiros

## Slide 2 — O desafio

A Corretora Valor Alto processa cerca de 2,5 milhões de transações por dia e enfrenta dificuldades para consolidar dados de diferentes fontes, resultando em relatórios gerenciais com atraso de até 48 horas. Além disso, a falta de governança sobre os dados tem gerado retrabalho e riscos de conformidade regulatória.

## Slide 3 — Nossa proposta

Implementar uma plataforma de dados lakehouse na nuvem Azure, utilizando Databricks e Python, para centralizar e governar os dados financeiros, reduzindo o tempo de geração de relatórios para menos de 2 horas e garantindo conformidade com as normas do setor.

## Slide 4 — Arquitetura e tecnologias

Azure · Databricks · Python

- Desenho e implementação da arquitetura lakehouse no Azure Data Lake Storage Gen2 com Databricks.
- Desenvolvimento de pipelines de ingestão e transformação de dados utilizando Python e Spark.
- Migração de cargas de trabalho on-premises para a nuvem Azure, incluindo bancos de dados SQL Server e arquivos CSV.

## Slide 5 — Como vamos trabalhar

- Discovery e Arquitetura (6 semanas)
- Implementação da Plataforma e Pipelines (18 semanas)
- Governança e Migração de Dados (12 semanas)
- Testes e Go-Live (4 semanas)

Duração total: 9 meses.

## Slide 6 — Por que nós

Experiência em Engenharia de Dados, Governança de Dados, Migração para Nuvem, com projeto anterior entregue para a Corretora Valor Alto. Equipe: 1 arquiteto de dados, 2 engenheiros de dados, 1 especialista em governança de dados e 1 gerente de projeto.
