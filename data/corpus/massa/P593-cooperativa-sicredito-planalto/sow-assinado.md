# SOW — Modelo de risco de crédito com Machine Learning para cooperativa de crédito

**Contratante:** Cooperativa Sicrédito Planalto · **Contratada:** NTT DATA Brasil · **Vigência:** 5 meses a partir do kickoff

## 1. Objeto

Desenvolver um modelo de risco de crédito baseado em Machine Learning para reduzir a inadimplência em 20% e diminuir o tempo de análise para menos de 1 dia, em 5 meses.

## 2. Escopo contratado

- Análise exploratória e engenharia de features com Python e bibliotecas de ciência de dados
- Desenvolvimento de modelos preditivos de risco de crédito utilizando Machine Learning (regressão logística, random forest e gradient boosting)
- Validação e ajuste de hiperparâmetros com técnicas de cross-validation e métricas como AUC-ROC e KS
- Implementação de pipeline de scoring em Python para integração com o sistema de análise de crédito
- Documentação técnica e transferência de conhecimento para a equipe interna do cliente

## 3. Entregáveis e aceite

- Relatório de análise exploratória e seleção de variáveis
- Modelo de risco de crédito validado com performance superior a 0,80 de AUC
- Documentação do modelo e manual de uso
- Workshop de capacitação para 10 analistas de crédito do cliente
- Dashboard de monitoramento de performance do modelo

Cada entregável é aceito pelo cliente em até 10 dias úteis após a entrega.

## 4. Fora do escopo

Sustentação após a operação assistida, licenças de software e infraestrutura do cliente.

## 5. Valor e condições

Valor total: R$ 3.120.000, faturado mensalmente conforme o cronograma.
